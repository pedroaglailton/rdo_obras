4. SEGURANÇA - DELETE DE RDO PROTEGIDO
============================================================

Arquivo: server.js - endpoint DELETE /api/rdos/:id

ANTES: Qualquer usuário podia deletar qualquer RDO
DEPOIS: Verificação de permissão adicionada
- Só o dono do RDO pode deletar
- Gestores podem deletar qualquer RDO
- Retorna 403 se não tiver permissão
- Retorna 404 se RDO não existir

CÓDIGO IMPLEMENTADO:
app.delete('/api/rdos/:id', (req, res) => {
  const rdo = db.prepare('SELECT usuario_id FROM rdos WHERE id=?').get(req.params.id);
  if (!rdo) return res.status(404).json({ error: 'RDO nao encontrado' });
  if (req.user.perfil !== 'gestor' && rdo.usuario_id !== req.user.id) {
    return res.status(403).json({ error: 'So o dono do RDO pode excluir' });
  }
  db.prepare('DELETE FROM rdos WHERE id=?').run(req.params.id);
  res.json({ ok: true });
});

5. API /api/rdos - DADOS EXPANDIDOS
============================================================

Arquivo: server.js - endpoint GET /api/rdos

QUERY ATUALIZADA:
SELECT r.*, 
  o.nome as obra_nome, 
  o.responsavel as obra_responsavel, 
  o.status as obra_status,
  l.comarca as cidade, 
  l.latitude as local_lat, 
  l.longitude as local_lng, 
  l.endereco as local_endereco
FROM rdos r 
LEFT JOIN obras o ON r.obra_id=o.id 
LEFT JOIN locais l ON (r.local = l.nome OR ...) AND l.ativo=1
WHERE 1=1

DADOS ADICIONADOS:
- o.responsavel as obra_responsavel
- o.status as obra_status
